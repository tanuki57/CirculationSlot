# 気休めスロット

スマートフォンでも遊びやすい、スロットとミニゲームのブラウザゲームです。追加ソフトやサーバーは不要で、GitHub Pagesに公開できます。

## ゲーム内容

- **通常スロット**：3回の無料SPINのあと、1回50コイン（ギャンブラーバフ装備中は60コイン、回転割引装備中は各10コイン引き）。絵柄が3つ揃うと払い戻し。
- **追加スロット**：最高所持コイン10,000枚でダブルアップ、30,000枚でボーナスリール、50,000枚で3リールチャレンジが解放されます。ダブルアップは当たり報酬を賭けて50%で倍増、失敗すると賭けた報酬を失います。ボーナスリールは当たり報酬に×2（50%）、×3（20%）、またはハズレ（30%）を適用します。3リールチャレンジは通常のSPIN料金を払い、各リールを手動で止めて3つ揃えると通常報酬を獲得します。
- **絵柄抽選・報酬**：1スピンごとにハズレまたは当たり絵柄を抽選します。通常確率はハズレ約83.84%、🍒🍋🍊各5%、🔔1%、⭐0.1%、💎0.05%、7️⃣0.01%です。報酬は🍒🍋🍊各150、🔔700、⭐2,000、💎5,000、7️⃣10,000コイン。🔔はさらに無料SPINを5回獲得します。⭐・💎・7️⃣が当たると、画面中央に獲得コイン数を大きく表示する演出が出ます。設定画面には通常時の確率と報酬を表示します。
- **ミニゲーム**：タイミングストップ、ハイ＆ロー、数字記憶。
- **タイミング判定**：MISS・GOOD・GREAT・PERFECTの各ゾーンを色とラベルで表示。集中力バフを装備すると成功ゾーンが広がります。
- **タイムアタック**：10,000コイン到達TA、10分TA、5分TA。開始後は通常スロット画面へ移動し、同じリールとSPINボタンで挑戦します。TAコインは通常コインと別管理です。時間制TAは制限時間を最後まで遊んだ場合のみ完走報酬を獲得し、途中終了ではTコインは付与されません。完走報酬は10,000コインTAと10分TAが1 Tコイン、5分TAが0.5 Tコインです。TA中もミニゲームでTAコインを獲得できます。
- **バフ・実績・ログインボーナス**：24種類のバフを購入・装備できます。価格は1,000〜34,000コインで、既存バフの上位版もあります。同じ系統の通常版と上位版を両方装備すると、上位版の効果にほどよいボーナスが加わります。実績は25種類あり、スロット・ミニゲーム・TA・バフ収集の進行に応じて解除されます。7日周期のログイン報酬もあります。TコインはTA完走で獲得します。
- **バフ装備枠**：同じバフは重複して装備できません。装備枠の拡張コストは1 Tコインから始まり、拡張するたびに1枚ずつ増えます。
- **セーブ**：進行状況は端末のブラウザ内（localStorage）に保存されます。

## GitHub Pagesで公開

1. GitHubで新しい空のリポジトリを作ります。
2. このフォルダ内のファイル（`index.html`、`style.css`、`app.js`、`manifest.webmanifest`、`icon.svg`、`sw.js`、`README.md`）をリポジトリのルートへアップロードします。
3. リポジトリの **Settings → Pages** を開きます。
4. **Build and deployment** の Sourceを **Deploy from a branch**、Branchを **main**、Folderを **/(root)** にして保存します。
5. Pagesに表示されたURLを開くと遊べます。HTTPSで開くと、対応ブラウザではホーム画面への追加とオフライン起動も利用できます。

## ローカルで遊ぶ

`index.html`をブラウザで開けばゲームを遊べます。Service Workerによるオフライン機能を確認する場合はGitHub PagesなどHTTPSのWebサーバーから開いてください。

## ファイル構成

| ファイル | 内容 |
|---|---|
| `index.html` | 画面とゲームUI |
| `style.css` | スマートフォン向けレイアウト、演出 |
| `app.js` | ゲーム処理、セーブ、各モード |
| `manifest.webmanifest` | インストール可能なWebアプリの設定 |
| `sw.js` | 静的ファイルのキャッシュとオフライン対応 |
| `icon.svg` | アプリアイコン |

## 注意

セーブデータは利用中のブラウザに保存されます。ブラウザのデータを消去したり、別の端末・ブラウザで開いたりすると共有されません。クラウド同期は行いません。
